# Event-B 前三讲学习包

从能在 Rodin 中亲手建好一个模型开始，到能解释银行转账、单车道桥与机械压力机的精化和证明。阅读时可以把中文讲义和 Rodin 并排打开。讲义使用工程中的真实组件名、事件名和标签，并标有回看原课件的页码。

**下载完整包**或单独获取可以在 Rodin 导入向导里选择的工程 ZIP，请打开 [GitHub Release](https://github.com/TomHaoZi/event-b-rodin-course/releases/tag/v1.0.0)。

## 第一次使用

1. 阅读[操作手册](01-软件手册/Rodin操作手册.md)的第 1、2 节，安装 Rodin，然后选 **File → Import… → General → Existing Projects into Workspace**。
2. 完整包解压后，用 **Select root directory** 选择 `03-Rodin工程`。若下载的是 `Rodin-Projects.zip`，在同一向导选 **Select archive file**，直接选择 ZIP。先只勾选 `L2_Bridge` 即可。
3. 在 **Event-B Explorer** 展开 `M0_Capacity`。读 `ML_out` 的守卫 `n < d` 和动作 `n ≔ n + 1`。取容量为 2，手算连续进车两次后能否进第三辆。手册第 3 节带你从空白工程复建这一层，第 5 节解释它的证明。
4. 在[第一讲](02-课程讲义/01-形式化方法入门.md)学习上下文、机器、事件和见证，再分别跟着[第二讲](02-课程讲义/02-单车道桥.md)和[第三讲](02-课程讲义/03-压力机.md)走完整条精化链。

## 课件与重建说明

第一讲按 `course 1.pptx` 的幻灯片序号引用，第二、三讲按 `course 2 car.pdf`、`course 3 press(1).pdf` 的 PDF 页序引用，封面为第 1 页。动画的连续画面按场景分组讲解。车库门、ATM 等概念图见第一讲；正式案例与有教学价值的错误草稿分别在工程索引和反例实验中定位。

配套工程依照课件的公式与需求重建。讲义标出补全的定义、命名差异及课件中会改变公式含义的笔误。例如第三讲的门与离合器周期条件，应结合后面的反例和精化公式阅读。官方软件文档列在操作手册相应步骤旁。阅读原页时请使用自己的课件副本。
